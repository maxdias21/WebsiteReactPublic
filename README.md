Projeto Pausado

Este projeto foi iniciado como parte dos meus estudos em React, porém foi pausado temporariamente.

Durante o desenvolvimento, percebi que precisava melhorar minhas habilidades em CSS e estilização para criar interfaces mais personalizadas sem depender de bibliotecas como Bootstrap.

Por isso, decidi:

estudar CSS com mais profundidade,
praticar responsividade e layouts,
e iniciar um novo projeto aplicando esses conhecimentos.

Mesmo pausado, este projeto foi importante para meu aprendizado em:

React
Componentização
Gerenciamento de estado
Estruturação de aplicações front-end
